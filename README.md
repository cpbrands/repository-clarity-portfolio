# Repository Clarity Portfolio

Evidence-based GitHub repository auditing and documentation reconciliation, performed with AI assistance and human-controlled authority.

## What I Do

I inspect an existing GitHub repository at an exact commit and produce a plain-English map of:

* What is authoritative.
* What is proposed or unfinished.
* What is missing, stale, duplicated, or contradictory.
* What the available evidence actually proves.
* What should be addressed next.

My work is designed for repository owners who need clarity before approving changes, inheriting a codebase, or commissioning further development.

## Case Study

### [Verified Execution: Turning a Fast-Evolving Repository into an Auditable Source of Truth](case-studies/verified-execution.md)

Verified Execution is a public architecture and protocol repository for authorization infrastructure. The case study shows how I:

* Established an exact authoritative baseline.
* Mapped specifications, decisions, proposals, tasks, and validation material.
* Identified documentation and governance gaps.
* Directed bounded corrections through branches and pull requests.
* Used automated validation without confusing passing checks with authorization.
* Kept final interpretation and merge authority under human control.

**Evidence repository:** [cpbrands/VerifiedExecution](https://github.com/cpbrands/VerifiedExecution)

### [NanoClaw Dashboard: Finding a Broken Install Path in a Buildable TypeScript Repository](case-studies/nanoclaw-dashboard.md)

A read-only shadow audit of an unfamiliar public repository showed that successful installation and compilation did not guarantee accurate onboarding documentation. The audit identified a package-identity migration that left the README install command pointing to a package that returned `404 Not Found` from the public registry.

**Evidence repository:** [nanocoai/nanoclaw-dashboard](https://github.com/nanocoai/nanoclaw-dashboard)

## Operating Principle

> An AI-generated statement is not evidence. Repository contents, commit history, diffs, check output, and observed behavior are evidence.

## Scope

This portfolio demonstrates repository-state analysis, documentation integrity, authority mapping, structured gap analysis, and reviewable GitHub workflows.

It does not claim independent senior full-stack engineering, production deployment, security certification, penetration testing, database migration, or operation of live customer systems.

## Starter Engagement

The initial Repository Clarity Audit is a fixed-scope review of one small repository. The owner receives:

1. An exact audit baseline.
2. A repository and authority map.
3. Evidence-backed findings.
4. A prioritized gap register.
5. A plain-English final report.
6. When agreed, one reviewable documentation pull request.

Production changes, deployment, security certification, and major code repair are outside the starter audit.
